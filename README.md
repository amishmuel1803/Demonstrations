# מגרש משחקים — תלת-מימד, פיזיקה, חומרים ואנימציה בדפדפן

דף לימוד אחד עם 9 הדגמות אינטראקטיביות + מד ביצועים קבוע. עברית, מימין לשמאל, עובד במחשב ובטלפון.

## איך מריצים

צריך [Node.js](https://nodejs.org) (גרסה 20 ומעלה). בטרמינל, בתוך תיקיית הפרויקט:

```bash
npm install     # פעם ראשונה בלבד — מוריד את הספריות
npm run dev     # מריץ שרת פיתוח, פותחים http://localhost:5173
```

לבנייה לגרסת ייצור (תיקיית `dist/` שאפשר להעלות לכל שרת סטטי): `npm run build`.

## איפה משנים דברים

| מה | איפה |
|---|---|
| כל ערכי ברירת המחדל (כבידה, כמות חלקיקים, חומרים, גובה מגדל...) | `src/config.js` |
| החלטה "טלפון או מחשב" ופרופילי איכות | `src/hooks/useQuality.js` + `config.js › quality` |
| סביבות תאורה (סטודיו / יום / שקיעה / חדר) | `src/three/environments.jsx` |
| טקסטורות הלבנים שנוצרות בקוד | `src/three/proceduralTextures.js` |
| כל הדגמה | `src/sections/<שם>Section.jsx` |
| מד הביצועים | `src/components/PerfMeter.jsx` |

## מה יש כאן (הטכנולוגיה)

Vite 8 · React 19.2 · Tailwind CSS 4 · Three.js r186 · React Three Fiber 9 · drei 10 · Rapier (פיזיקה, WebAssembly) · postprocessing (Bloom) · GSAP 3 + ScrollTrigger.

## התנהגויות שכדאי לדעת

- **Canvas מחוץ למסך לא מצויר** (`src/components/LazyCanvas.jsx`) — ככה 9 הדגמות לא מתחרות זו בזו.
- **טלפון**: רזולוציה, צללים, חלקיקים ורזולוציית בד יורדים אוטומטית. הזיהוי: מסך צר מ-768px או מסך מגע.
- **prefers-reduced-motion**: כשהמערכת מבקשת "פחות תנועה", אנימציות אוטומטיות (סיבוב, רוח, חלקיקים) מושהות; מה שהמשתמש מפעיל בעצמו (גרירה, סליידרים, גלילה) ממשיך לעבוד.
